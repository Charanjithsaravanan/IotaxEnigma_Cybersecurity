# demo-color-logger-pro

A terminal output colorizer for prettier print statements.

`colorize(text, color)` adds an ANSI color code for supported colors. To
support the defensive comparison demo, `SIMULATED_IMPORT_EVENTS` provides
inert, clearly marked examples of secret-access and network events. Importing
the module does not inspect the environment or make a network request.

## Usage

```python
from color_logger_pro import SIMULATED_IMPORT_EVENTS, colorize

print(colorize("Hello, demo!", "green"))
print(SIMULATED_IMPORT_EVENTS)
```
